# Online Education Data Analysis

## Project Overview

This project analyzes student learning behavior and course performance using SQL, Python, Pandas, and Power BI.

## Dataset

Open University Learning Analytics Dataset (OULAD).

The original dataset is stored locally and is not uploaded to GitHub because some files exceed GitHub's file size limit.

## Project Objectives

1. Analyze student learning behavior.
2. Compare course completion and withdrawal rates.
3. Explore the relationship between learning activity and academic performance.
4. Identify students with potential dropout risks.
5. Analyze assessment submission behavior.
6. Provide data-driven recommendations for education operations.

## Technology Stack

- SQL
- Python
- Pandas
- Jupyter Notebook
- Power BI
- Git and GitHub
